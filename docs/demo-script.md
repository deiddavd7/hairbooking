# Demo Script

Use this script for a 2-3 minute portfolio or thesis demo.

## 1. Login And Onboarding

- Open the app in Xcode.
- Log in with any email and a password of at least 4 characters.
- Complete onboarding.

Message to present: the app is a local-first prototype for appointment-based studios.

## 2. Agenda And Booking

- Open **Agenda**.
- Show the daily calendar and existing bookings.
- Open **Prenota**.
- Create or edit a booking.
- Explain conflict detection per professional and service duration.

Message to present: bookings are modeled with interval logic and validated before saving.

## 3. Clients And Services

- Open **Clienti**.
- Search for a client.
- Open the client profile and show history, references and communication links.
- Open **Studio > Catalogo servizi**.
- Show editable prices, durations and service categories.

Message to present: the prototype covers the main CRUD workflows of a real studio.

## 4. Smart Desk

- Open **Smart**.
- Show suggested slots, no-show risk, demand segments and inactive clients.

Message to present: the decision-support logic is explainable and can evolve into predictive analytics.

## 5. Reports

- Open **Report**.
- Show average ticket, completion rate, service performance and 7-day capacity utilization.

Message to present: the app transforms operational data into management indicators.

## 6. Technical Close

- Mention SwiftUI, Codable local persistence, XCTest, GitHub Actions and documentation.
- Point to `docs/architecture.md` and `docs/thesis-proposal.md`.
